# ゆっくり実況の「ノリ」の分析

作成: 2026-10-07。

## データの状況（正直に）

- YouTube に接続できないため、動画の中身を自分で大量に見ることはできない
- 手元にある実データは **参考動画（ふつうのくま企画・約60分）の文字起こし全文1本**（`COMPETITORS.md` S-01）。今いちばん伸びている型の1つの、実際の会話
- Web 検索で分かった一般的な特徴: テンポの良さと気軽さ／キャラの濃さ（4〜6人で回すチャンネルもある）／「ゆっくり実況」そのものをネタにするメタ発言（例: 100菌）／ボケもツッコミも両方こなす掛け合い
- **2本目（2026-10-07 追加）**: ユーザーが貼った、Among Us（闇鍋）のゆっくり実況の文字起こし全文（約2時間47分）。チャンネル開設約4年・同シリーズ約250本の、続いているチャンネル。プレイヤー役（「私」・丁寧語）＋霊夢＋魔理沙の3人で実況し、コラボ相手の生声も入る形式
- これで n=2。両方に共通する特徴を「ゆっくり実況のノリ」の芯として扱う

## 文字起こしから抜き出した「ノリ」の特徴

| 特徴 | 文字起こしの例（要約・短い引用） | 最初の台本サンプルにあったか |
|---|---|---|
| **セリフが短い** | 1セリフは長くて1〜2文。ツッコミは一言（「何の説明だったんだよ」「泣くぞ」） | ×（説明的で長い） |
| **情報→すぐ茶化す** | 真面目な説明の直後に、必ずボケかツッコミで崩す。1〜2セリフに1回は笑いどころ | △（説明が続く） |
| **視聴者・動画そのものをいじる（メタ）** | 冒頭から視聴者に話しかける。「横動画を見ているあなたは〜」→「見てる方が〜だろ」。編集・尺・YouTube の話をネタにする | ×（なし） |
| **ボケとツッコミが入れ替わる** | 説明役も平気でボケる。ツッコミ役も悪ノリする。役割は固定しすぎない | ×（魔理沙が常に正論） |
| **天丼（同じネタの繰り返し）** | 「反面教師」「大学生基準」「フランちゃん」が何度も出てくる | ×（なし） |
| **唐突なたとえ・固有名詞** | ドラえもん、大谷翔平、サメ、メントスコーラ | ×（なし） |
| **少し毒のある言い方** | 「普通に引いたわ」「どこ目指してんだお前」など、仲が良い前提の口の悪さ | ×（行儀が良すぎた） |
| **テロップ・効果音で笑わせる** | 会話だけでなく、画面の文字や音で落とす | ×（テロップは状況説明だけ） |
| **自虐** | 自分の失敗やダメさを自分で言う | △ |

## 最初のサンプルが「ノリが違う」原因（診断）

1. **説明書みたいな会話**だった（文が長い・論理的・丁寧）
2. **魔理沙が正論ばかり**で、一方通行のツッコミになっていた
3. **メタ・視聴者いじり・天丼・テロップのボケ**がゼロだった
4. 笑いどころの間隔が長かった

## 台本のルール（暫定）

- 1セリフは1文まで。説明が長くなったら分けて、間にツッコミを挟む
- 説明を2セリフ続けたら、次は必ず崩す
- 霊夢は「勢い」、魔理沙は「計画」だが、**魔理沙もボケる**。2人とも少しずつダメ
- 冒頭は視聴者への話しかけ（メタ）から入る
- チャンネル共通の天丼を2〜3個作る（例: 霊夢の雑な四捨五入、「市長です」テロップ、道路への執着）
- テロップで落とす場面を各パートに1つ入れる
- 口の悪さは「仲が良い前提」の範囲まで。本気の悪口・他人や特定の実在の人への攻撃はしない

## 2本目（Among Us 闇鍋・約2時間47分）から分かったこと

| 特徴 | 例（要約・短い引用） | 1本目と共通か |
|---|---|---|
| **一言の決め文句（タグ）が2〜3セリフごとに入る** | 「〜定期」「〜ゲーミング」（人任せゲーミング）「〜チャンネル」（手のひら回転チャンネル、実質お料理チャンネル）「圧倒的〜」「〜あるある」「草」 | ○（1本目より頻度がずっと高い） |
| **語り手（プレイヤー役）が丁寧語で淡々と悪いことを言う** | 丁寧語で「無料1キル」「圧倒的愚策」など。悪役ぶりと丁寧さの落差 | △ |
| **毎回の冒頭に意味のない茶番** | 「道端で困っていたおばあちゃん30人を助けた」「全国の山田を従わせる魔法」など、本編と関係ない一発ネタ → すぐ本題へ | ×（1本目にはない） |

| **ゲームの説明は短く、すぐ茶化す** | 役職の能力を1〜2文で説明 → 即ボケ | ○ |

## 2本を通した「ノリの芯」

1. **1セリフは短い。説明は1〜2文で切って、すぐ茶化す**
2. **笑いの間隔は2〜3セリフに1回**（決め文句・ツッコミ・テロップのどれか）
3. **メタ・自虐・天丼・パロディ**を混ぜる
4. **看板コーナーを毎回やる**（こちらは「決算」）
5. 口は悪いが、仲が良い前提

## このチャンネルへの当てはめ

- **冒頭に10〜20秒の茶番**を毎回入れる（本編と関係ない一発ネタ → 「というわけで今回は〜」で本題）
- **テロップを「3人目のツッコミ役」にする**: 2本目の決め文句の多くは、3人目の声として入っていた。こちらは声を増やさず、**テロップで一言の決め文句を入れる**（音声の作業が増えないので編集が軽い）
- 霊夢・魔理沙の2人は維持（「勢い」と「計画」）。ただし魔理沙も悪ノリする
- 天丼を最初から用意しておく: 霊夢の雑な四捨五入／「※市長です」テロップ／途中で唐突に入る「高評価よろしく」系のネタは、2本目と被るので**別の形に変える**（例: 決算の最後に毎回「霊夢の言い訳」）
- 2本目に固有の言い回し（チャンネル名入りの看板・特定の決め台詞）は使わない。「定期」「ゲーミング」「圧倒的」「草」などのネットスラングの型は一般的なので使ってよい

## 注意（正直な評価）

- **このノリは笑いの密度が高いぶん、台本を書く時間が増える**。編集1分=1時間の見積もりは、このノリが前提だと甘い可能性がある → 1本目で必ず実測
- **街づくりは Among Us より出来事が少ない**。Among Us はゲーム自体が騒動を起こすが、街づくりは静か → 笑いを台本で作る比率が高くなる。初見の失敗・早送り＋テロップのボケで補う

## 3本目（Minecraft・飛行船MOD・約2時間50分）から分かったこと

ユーザーが貼った文字起こし全文（2026-10-07）。チャンネル登録者30万人。9人でのマルチプレイ。MODで空飛ぶ船（拠点ごと移動する）を作って旅をする企画。実況は「プレイヤー役（主人公・丁寧語）＋ツッコミ役」の2人。

| 特徴 | 例（要約・短い引用） |
|---|---|
| **主人公がボケで悪役** | 主人公が平然とひどいことを言う／する（村を「物資補給所」と呼んで根こそぎ持っていく、村人を「山猿」と呼ぶ）。ツッコミ役が良心として止める（止まらない） |
| **主人公が自分でゲームの仕組みを1〜2文で説明する** | 「バルーンブロックと舵を作れば飛べる」→ すぐボケ。ツッコミ役は解説しない |
| **毎回同じ形のツッコミ（決め文句）** | 「〜に涙が止まらない」が何十回も出る。「〜やめろ」「人の心ないんか」 |
| **ゲーム内の物に名前をつけて、キャラにする** | 小型船を「ボロカス号」と呼び、最後まで何度も出てきて扱いがひどくなっていく（天丼） |
| **自業自得の大事故が最大の見せ場** | 村を空爆しようとして自分の船を爆破 → 落ち込む → 立て直す。この流れが一番盛り上がる |
| **長い話の伏線回収** | 冒頭で置いてきた最初の船を、最後に取りに戻って締める |
| **メタ・自虐** | 編集で病んで温泉旅行、「20分作って1時間休憩」、登録者30万人記念を船に飾る |
| **唐突な脱線** | 「40年後に群馬県が独立する」など、意味のない一発ネタ |
| **視聴者参加** | メンバーの部屋の人気投票（約4,300票） |

## 3本を通した「ノリの芯」（v2）

1. **セリフは短い。笑いどころは1〜2セリフに1回**（3本とも）
2. **主人公がボケ（ときに悪役）、相方がツッコミ（良心）**。ゲームの説明は主人公が1〜2文で済ませる（3本とも）
3. **決め文句（ツッコミの型）を持つ**：「〜定期」（2本目）、「〜に涙が止まらない」（3本目）。チャンネルの口癖になる
4. **ゲーム内の物をキャラにして天丼にする**（3本目のボロカス号）
5. **自業自得の大事故 → 立て直し**が山場（1本目は戦略の失敗、3本目は空爆の自爆）
6. **冒頭と最後をつなぐ伏線回収**（1本目・3本目）
7. メタ・自虐・唐突な脱線

## 当てはめ（v2。このチャンネル用のルール）

- **霊夢＝主人公・ボケ・悪役寄り**。勢いで街を広げ、市民をコスト扱いする。ゲームの仕組みは霊夢が1〜2文で説明する
- **魔理沙＝ツッコミ・良心**。解説はほぼしない。霊夢の無茶を止める（止まらない）
- **このチャンネルの決め文句（候補）**：霊夢「必要経費です」（どんな犠牲もこれで片付ける）／魔理沙「決算に響くぞ」（看板の「決算」につながる）
- **毎回、道やエリアに名前をつけてキャラにする**（例: 霊夢が自分の名前をつけた「霊夢通り」が毎回渋滞の元凶になる）
- **1本に1回は自業自得の大事故**を見せ場にする（初見なので自然に起きるはず。起きた出来事をそう構成する）
- 冒頭で出したネタを、決算で回収する
- 他チャンネル固有の決め文句（「〜に涙が止まらない」「人外の力集結」など）は使わない

## 戦略面の示唆（ノリ以外）

- **工業寄りの Minecraft MOD でも、登録者30万人規模で成立している例**。ただし、売っているのは工業の説明ではなく「空飛ぶ拠点で旅をするロマン」「事故」「仲間とのドタバタ」。仕組みの説明は1〜2文だけ。1本目（参考動画）の「工業は伸ばしにくい」と矛盾はせず、**「工業を見せる」のではなく「ロマンと事故を見せる」なら成立しうる**という補足になる（n=1・大きなチャンネル・9人のマルチで、こちらは1人。そのまま当てはまらない）
- 9人のマルチは出来事（事故・喧嘩・遅刻ネタ）を勝手に生む。**1人プレイのこちらは出来事が少ない** → 主人公の「勢い」で事故を起こす設計がより大事になる
