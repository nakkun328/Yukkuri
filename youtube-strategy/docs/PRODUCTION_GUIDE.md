## 1. ゆっくり実況の特徴（9本のデータから）

「◯/9」は、その特徴がはっきり見られた本数（文字起こしの分析からの判定なので目安。テロップや画面は文字起こしに残らないため、実際はもっと多い可能性がある）。

| 特徴 | 何本で見られたか | 中身 |
|---|---|---|
| **セリフが短い** | 9/9 | 1セリフは長くて1〜2文。ツッコミは一言 |
| **笑いの間隔が短い** | 9/9 | 1〜3セリフに1回は笑いどころ（ボケ・ツッコミ・テロップ・効果音） |
| **主人公がボケ、相方がツッコミ** | 9/9 | 主人公は倫理観が低い・勢いで動く。相方が止める（止まらない） |
| **ゲームの説明は短く、すぐ茶化す** | 9/9 | 仕組みは主人公が1〜2文で言い、直後に崩す。説明を続けない |
| **天丼（同じネタの繰り返し）** | 9/9 | 決め台詞・物の呼び名・同じ失敗。最後に回収して山場にする |
| **メタ・自虐** | 9/9 | 編集・尺・撮影時間・視聴者の話をネタにする |
| **自業自得の事故が山場** | 7/9 | 自分の判断ミスで大失敗 → 立て直し |
| **毎回同じ冒頭・締めの型** | 7/9 | 決まった挨拶や締めの一言で「いつもの番組」感を出す |
| **長い作業は結果だけ見せる** | 6/9 | 早送り・全カットの後、完成形へのツッコミで笑いを取る |
| **フラグ→回収** | 5/9 | 自信満々の宣言 → 直後に失敗 |
| **数字で進み具合を見せる** | 5/9 | 人口・金額・種類数。目標に対する割合で言うとダメさが伝わる |
| **心の声（判断の理由を口に出す）** | 4/9 | 視聴者が判断についていける |
| 口は悪いが仲が良い前提 | 9/9 | 本気の悪口・実在の人への攻撃はしない |

**伸びている長尺はほぼすべて「出来事が多い」**。マルチプレイは仲間が勝手に事件を起こすが、こちらは1人プレイ。**事件は霊夢の判断ミスで起こす**のがこのチャンネルの前提。

## 2. このチャンネルの型（決まっていること）

| 項目 | 内容 |
|---|---|
| シリーズ | 「初見・ゼロから12時間で、どこまで発展できるか」＋最後に「決算」。尺1時間前後 |
| 霊夢 | 主人公・ボケ・**見栄で街を盛るためにお金を溶かす市長**。言い訳がうまい。仕組みは自分で1〜2文で説明 |
| 魔理沙 | ツッコミ・**会計係**。数字でとがめる。解説はほぼしない |
| 決め文句 | 霊夢「必要経費です」（お金を使う場面だけ）／魔理沙「決算に響くぞ」 |
| 天丼 | 「霊夢通り」: 自分の名前の道に毎回お金をつぎ込み、毎回失敗の元凶になる |
| テロップ | 3人目のツッコミ役（【※完璧ではありませんでした】など） |
| 締め | 霊夢「以上、今期の決算でした」／魔理沙「来期はまともな市長でありますように」 |
| やらないこと | 選挙ネタ・立ち退きを笑いの中心にする・住民を抑圧する暴君キャラ（Cities 実況の定番。`ORIGINALITY.md`） |

## 3. 台本を書くとき

### 3.1 セリフの長さとテンポ

- **1セリフ＝1文**。読点が2つ以上になったら分ける
- **説明は2セリフまで**。3セリフ目は必ず崩す（ボケ・ツッコミ・テロップ）
- **笑いどころは1〜3セリフに1回**。5セリフ以上まじめが続いたら書き直す
- ツッコミは短く（「金額を聞いてるんだ」「市民より木が先か」）。理屈で長く返さない
- 1時間の動画で**同じ調子が3分続かない**ようにする（早送り・テロップだけの場面・決算前の予想などで変化をつける）

### 3.2 キャラを崩さない

- 霊夢は**悪いことを堂々と、丁寧に**言う。言い訳は筋が通っているほど面白い（「理にかなってるのが一番腹立つな」）
- 霊夢の悪さは**お金・見栄・言い訳**。住民をいじめる方向に行ったら書き直す
- 魔理沙は**数字で刺す**（「工事費÷通った車の台数＝1台◯万だぞ」）。魔理沙もたまに悪ノリしてよい
- 語尾: 霊夢「〜わ」「〜よ」「〜です（市長モード）」、魔理沙「〜だぜ」「〜だな」。**「だぜ」を毎セリフ付けない**（単調になる。3〜4セリフに1回くらい）

### 3.3 決め文句・天丼の使い方

- 「必要経費です」「決算に響くぞ」は**1本で各3〜5回まで**。毎回使うと効かなくなる。山場で1回、必ず使う
- 天丼は**3回目で回収**するつもりで置く（1回目: 紹介、2回目: 悪化、3回目: 大事故 or 決算で回収）
- 冒頭で出したネタを決算で回収する（例: 冒頭で作った霊夢通り → 決算で MVP とワースト両方受賞）
- フラグ（霊夢の自信満々の宣言）→ テロップで回収。**1本に3〜4回まで**

### 3.4 テロップ

- テロップは**声で読ませない**（YMM4 ではセリフとは別のテキストアイテムにする）
- テロップで落とすのは**事実の数字か、短い一言**（状況の説明【渋滞が発生しました】ではなく、【霊夢通り、2階建てになって渋滞も2階建て】のような結果の要約でオチをつける）
- 各パートに1つはテロップで落とす場面を入れる

### 3.5 ゲームの出来事の拾い方

- CS II の定番の見せ場: 渋滞・ゴミの埋立地が満杯・増税の失敗・バスの行列・公害・停電・断水。競合も使っているので、**出来事は同じでよいが、オチは霊夢のお金の使い方につなげる**
- 失敗は「原因探し→直す→まだ駄目」の3段で見せる
- 奇妙な挙動（車の変な動き・事故）を見つけたら、1台を追いかけて見せる
- 人口の節目（ゲーム内の都市ランク）をテロップにして章の区切りにする
- 長い作業は早送り → 結果を見せて一言ツッコミ

### 3.6 書いてはいけないこと

- 使用禁止リスト（`ORIGINALITY.md`）の言い回しと、**似た言い回し**
- 実在の人・自治体・団体を本気で悪く言うこと。災害や事故の実際の被害を連想させるネタ
- 東方の原作設定に頼ったネタ（このチャンネルは原作準拠ではない。知らない人が置いていかれる）

## 4. YMM4 でセリフを打つとき

### 4.1 読み間違いを防ぐ

ゆっくりボイス（AquesTalk）は漢字の読み・数字・英語をよく間違える。**全部のセリフを一度通して聞く**のが基本。

| よく間違える種類 | 例 | 対策 |
|---|---|---|
| 固有名詞・造語 | 霊夢通り（れいむ**ど**おり）、魔理沙 | YMM4 の辞書に登録する。**最初の1本で登録した単語は次から効く**ので、まとめて登録しておく |
| ゲーム名・英語 | Cities: Skylines II（シティーズスカイライン**ツー**）、RimWorld、MVP | 辞書登録、または台本の段階でカタカナで書く |
| 数字 | 4万8千人、12時間、◯◯万 | 漢数字とアラビア数字の混ざり方で読みが変わることがある。大きな数字は必ず聞いて確認。**◯◯ の仮の数字を残したまま出さない** |
| 同じ字で読みが違う語 | 「市（し／いち）」「今期（こんき）」「高架（こうか）」「決算」「経費」 | 聞いて違えば辞書登録 |
| 記号 | 「……」「〜」「！？」 | 「……」は無音にならず変な音になることがある → **沈黙はセリフで書かず、タイムラインに間を空ける** |

辞書に登録する候補（1本目の前にまとめて）: 霊夢通り／シティーズスカイライン／決算／必要経費／今期／来期／高架／会計係／RimWorld。

### 4.2 間（ま）

- ボケ → ツッコミの間は**短め**（0.2〜0.5秒くらい）。ゆっくりボイスは間が均等だと単調になる
- 天丼の回収・大事故の直後は**少し長めに空けて**から、テロップかツッコミを出す（「霊夢「……」魔理沙「……」」の場面は、無言の間＋立ち絵の表情で見せる）
- 同じ長さの間が続かないようにする

### 4.3 声と見た目

- 話す速さは2人でそろえる。1時間の動画なので、早すぎると聞き疲れる
- 「？」で終わると語尾が上がる。疑問でないセリフに「？」を付けない。「！」は多用しない（全部が叫びになる）
- 立ち絵の表情を場面ごとに変える（霊夢のドヤ顔 → 失敗で青ざめる、魔理沙の呆れ顔）。**表情の切り替えはテロップと同じくらい笑いを作る**
- 効果音は落ちの場面だけ。毎セリフに付けると効かなくなる

### 4.4 作業を速くする（編集1分＝1時間を縮めるために）

- キャラ・字幕・テロップ・決算画面は**テンプレート化**して毎回使い回す
- 台本はテキストで先に書き切ってから YMM4 に流し込む（YMM4 上で考えながら打たない）
- 毎回、**1本にかかった時間を工程ごとに記録**（台本・セリフ打ち・読み修正・テロップ・素材・書き出し）。どこが遅いかを次の1本で直す

## 5. 録画・プレイ中にやること

ゆっくりの声は後から入れるので、**プレイ中の気持ちや出来事はその場で記録しないと消える**。初見の反応は二度と取れない。

- **メモの型**（1行ずつ）: `時刻（録画の何時間何分）｜出来事｜霊夢の一言の案｜数字`
  - 例: `5:12｜霊夢通りが真っ赤｜「混んでるわね」｜渋滞度◯%`
- **お金の記録**: 霊夢通りに使ったお金は**その都度メモ**（決算の看板の数字になる。後からは集計できない）
- 決算用に、**1時間ごとに統計画面のスクリーンショット**（人口・資金・収支・交通・幸福度）
- 「あ、これ失敗した」と思ったら必ずメモ。山場の候補になる
- 12時間の数え方（ポーズ中を含めるか）を撮影前に決めて、守る
