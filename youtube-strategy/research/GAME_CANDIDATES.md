# ゲーム候補の判定

最終更新: 2026-10-07。判定は **やる / テストする / 今はやらない**。データの凡例: ⚠️二次情報（要再確認）／❌未取得。

分類は指示.md §12 の不動産分類（一等地・安定収益・成長株・投機・イベント会場）。

| ゲーム | 分類 | 判定 | 主な根拠・懸念 |
|---|---|---|---|
| Minecraft + Create | 一等地 | **やる**（001） | 入口が大きく説明しやすい。Create DL数は約2億（⚠️）。懸念: 競合調査が未了、MODバージョン更新 |
| Factorio | 一等地 | **やる**（002）※企画を一般化する条件付き | 同時接続が長期安定（⚠️ 月平均 約1.5〜1.8万）。懸念: 説明が難しい。縛り・数字で一般性を作る |
| Satisfactory | 一等地候補 | **テストする**（003の代案） | 同時接続 約2.2万、24hピーク 約2.7万（⚠️2026-10）。FactorioとCreateの中間で、客層が近いはず（要検証）。過去ピーク数値が情報源で食い違う（104,677 と 185,957）ので要再確認 |
| Cities: Skylines II | 安定収益／投機寄り | **テストする**（003案） | 人口小さめ（⚠️ 平均約9,500）、運営交代・追加コンテンツ続き＝アップデート依存。分かりやすさとBefore/Afterは強い。やるなら20時間以内に抑える |
| Kerbal Space Program（1） | 安定収益 | **テストする**（後ろの順番） | 宇宙開発は題材が長寿命。ただし2026-05の同時接続約1.2万は**アルテミスII特需の可能性が高く**、人口の平常値ではない（⚠️）。KSP2は開発停止（2024年）で、続編の期待は薄い |
| Hearts of Iron IV | 安定収益 | **今はやらない**（再評価はG4以降） | 人口は大きく長期だが、工業/自動化視聴者とは別。「システム攻略」にどう寄せるか企画が未設計。データも未取得（❌） |
| Arknights: Endfield | 成長株／投機 | **今はやらない**（Steam版の動向待ち） | 2026-01-22 発売。事前登録3,500万（⚠️）。工業（基地建設・生産ライン）要素は強いが、ガチャ型RPGで長期人口は未確認。Steam版は発表済みで日付は未定（⚠️）。やるなら発売直後に1〜2本の投機枠 |
| Palworld | 成長株／イベント | **今はやらない** | 人口の変動が激しく、資産より集客向き（指示.md §13）。最新データ未取得（❌） |
| Core Keeper | 要検証 | **今はやらない**（調査待ち） | 相性は良いが、市場規模・競争・長期性が未確認（❌） |
| Find the Needle | 投機 | **今はやらない**（情報不足） | 検索結果では「500万個の干し草から針を探す」型の話題作という情報のみで、工業・自動化との相性の裏付けが取れていない（⚠️）。「相性が非常に高い」という前提はこの時点では未検証。話題性だけならイベント会場枠 |
| R.E.P.O. / PEAK | イベント会場 | **今はやらない** | ブランドとの接続が弱い（指示.md §13）。友達との掛け合いなど別の武器がある場合のみ |
