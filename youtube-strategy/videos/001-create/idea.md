> ⚠️ 2026-10-07 更新: 時間予算（週12h）に合わせ、**プレイ時間を15〜20時間に縮小**する方針（`docs/CHANNEL_STRATEGY.md` §6.5）。下のプレイ時間・終了条件は縮小後の規模に合わせて見直す。完成尺は45〜70分を維持。

## 一文企画

**サバイバルのMinecraftで、手作業ゼロで勝手に素材が作られ続ける巨大工場を、何もない状態から作る。**

## 視聴者がクリックする理由

- Create を知らなくても「何もしなくても全部作られる」の意味が分かる
- 「何もない → 巨大」という成長の快感が見た目で伝わる
- Minecraft という大きな入口がある

## ゴール・終了条件（撮影前に固定）

候補（要ユーザー判断・どれか1つに絞る）:

- **A（推奨）**: 「ボタン1つ／チェストに入れるだけで、ネザライト装備一式まで全自動で出てくる」状態。最後に毎分の生産量と所要時間を数字で見せる
- B: 「全アイテム自動倉庫」。扱うアイテム数が大きく、見た目も派手だが、制作量が膨らみやすい
- C: 「手でクラフトしないで、エンドラ討伐まで」。縛りフォーマットとして強いが、Create 以外の要素が増える

終了条件が決まるまで撮影しない。**最終成果は数字で示す**（生産量・面積・総プレイ時間）。

## 想定プレイ時間・完成尺

- プレイ: 30〜45時間（上限45時間。超過時は規模を縮小）
- 完成尺: 50〜65分（面白い素材が45分なら45分）

目安:
| 時間 | 内容 |
|---|---|
| 0〜5h | 序盤・素材集め（手作業のつらさを見せる） |
| 5〜12h | 最初の自動化 |
| 12〜25h | 工場拡張 |
| 25〜35h | 巨大化 |
| 35〜45h | 最終目標・仕上げ・撮影 |

## 最大のリスクと対策

| リスク | 対策 |
|---|---|
| 「Create解説」になって一般視聴者が離脱 | 設備名ではなく「何が自動になったか」で語る。専門用語はテロップで1行説明、深掘りは中盤以降 |
| 競合が多い（Create 動画は海外・国内ともに多数。**未調査**） | Phase 3 で同種企画の小規模チャンネルの伸びを確認してから撮影。差別化は**終了条件と数字**で作る |
| MODのバージョン更新で動画が古くなる | タイトル・サムネにバージョンを入れない。バージョンは概要欄に記載 |
| 30〜45時間が重く、中だるみ・撮影の失敗 | 撮影前に「見せ場」を事前に10個ほど決め、素材の取捨選択基準にする（`plan.md`） |
| 1本だけで終わる | 次動画への導線を最初から設計（下記） |
