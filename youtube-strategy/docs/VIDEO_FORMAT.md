# 動画フォーマット（視聴体験を見える形で統一する）

C1 の対策: 「視聴体験の統一」を、視聴者に**見える**形にする。

## 尺

- 目標 45〜70分。60分に合わせるために素材を残さない

## 成長物語の構成（全動画共通）

1. **0:00** 最終形を見せる
2. **0:30** 開始地点（何もない）
3. 序盤: 最初の小さな成功
4. 中盤: 規模拡大
5. **問題発生**（資源不足・渋滞・電力不足・設計ミス・敵・コスト増）
6. 改善 → さらに巨大化
7. 最終目標達成
8. 成果を**数字**で見せる（生産量・人口・面積・処理能力・資源量・総プレイ時間）
9. 次動画への導線

## 見える統一（案。ユーザー確認後に確定）

- シリーズ名（例: 「〇〇を全部自動化」）を決め、サムネ・タイトルに共通のラベルを入れる
- サムネ: 左=小さい／Before、右=巨大／After の構図を固定
- 冒頭: 最終形→開始地点の切り替えを固定
- 終盤: 数字表示（同じ画面レイアウト）

## 品質チェック（公開前）

- [ ] タイトルだけで「何がすごいか」が分かる（専門用語・バージョンなし）
- [ ] サムネの文字が少なく、ゲームを知らなくても意味が伝わる
- [ ] 最初の30秒で最終形と開始地点が出る
- [ ] 問題発生が少なくとも2回あり、解決が映っている
- [ ] 数字で成果を出している
- [ ] 概要欄・チャプター・字幕に検索語（ゲーム名＋やったこと）が入っている（F3対策）
- [ ] 次動画への導線がある
- [ ] 仮説を `experiments/HYPOTHESES.md` に書いた

## 制作中の判断基準

- 「この作業は動画に必要か？」を撮影中も確認（15時間・30時間時点でチェック）
- 目標から外れた寄り道は、面白くてもカットかサブ動画候補にする

## シリーズの型（2026-10-07 決定方向）

**「初見・ゼロから12時間で、どこまで発展できるか」＋最後に「決算」**
- 12時間（実時間）で区切る → 初見でもプレイ時間がぶれない・制作の時間予算と一致・どのゲームでも同じ型
- 決算: 毎回同じ画面レイアウトで、0時間目と12時間目の数字（人口・資産・規模など）を発表。チャンネルの看板
- サムネ: 型を固定（キャラ位置・配色・フォント・「12時間」のロゴ）。左に0h、右に12h

## 実況スタイル（2026-10-07 検討 → C で決定方向）

前提: 編集は**完成1分=1時間**で見積もる（ユーザー了承）。キャラは未定。「1人で淡々」「掛け合い・ボケツッコミ」どちらも可。

### 案

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| A. 1人で淡々 | 1キャラがプレイしながら淡々と話す | セリフが少なく編集が軽い。テンポよく見せやすい | 初見の「分からない」を説明する相手がいない。ゆっくりの強み（掛け合い）を使わない |
| B. 掛け合い中心 | 2キャラのボケ・ツッコミで進める | ゆっくりらしい。キャラが愛されやすい | セリフ（台本）が増え、編集が重くなりやすい |
| **C（推奨）. 初見の主役＋ツッコミ兼解説役** | 主役が初見でプレイし、もう1人がたまにツッコミ・ゲームの仕組みを補足する。主役のセリフ中心で、掛け合いは山場に絞る | 初見企画と噛み合う（主役の「知らない」を相方が拾い、ゲームを知らない視聴者への説明にもなる）。参考例の「淡々＋ボケツッコミ」と同じ型。セリフ量を山場に寄せれば編集時間を抑えられる | 相方の役割を固定しないと、ただの解説動画になる |

### キャラ選びの観点

- 参考例: **サムネで一番大事なのは「一目で誰の動画か分かる」**。定番キャラ（霊夢・魔理沙）だけでは他のチャンネルと区別しにくい → 立ち絵の位置・配色・フォントを固定して「型」で見分けてもらう
- 立ち絵: 定番の素材（費用ゼロ・すぐ使える）か、オリジナルの立ち絵（費用がかかるが見分けやすい。参考例はオリジナル）
- **権利の確認（要調査）**: 東方Projectの二次創作ガイドライン、ゆっくりボイス（音声ライブラリ）の収益化動画での利用条件、立ち絵素材の利用規約。収益化前に確認する

## キャラ候補（2026-10-07 提案）

前提: スタイルは「初見の主役（淡々と進める）＋ツッコミ兼解説役」。シリーズの型は「初見・ゼロから12時間＋決算」。参考例の主役は魔理沙（オリジナル立ち絵）なので、**魔理沙を主役にすると真似に見えやすい**。

| 案 | 主役（初見・プレイ） | 相方（ツッコミ・解説） | 長所 | 短所 |
|---|---|---|---|---|
| 1. 王道 | 霊夢 | 魔理沙 | 一目でゆっくり実況と分かる。視聴者が慣れている | 一番多い組み合わせで埋もれやすい。参考例とも近い |
| 2. 真面目が空回り | 妖夢 | 幽々子 | 真面目な主役が初見で計画を崩す姿が笑いになる。主役としては珍しい | 幽々子は解説役より「食べ物でボケる」役になりやすい |
| **3. 推奨: 紅魔館の決算** | **咲夜** | **パチュリー**（＋レミリアは冒頭と決算だけ） | 下記 | キャラが3人になる（レミリアのセリフは最小限にして編集量を抑える） |
| 4. 技術者 | にとり | 文 | 後で工業ゲームに広げるとき自然 | 主役としての知名度がやや低い |

### 推奨（案3）の理由

- **型と設定がつながる**:
  - 咲夜は「時間を操る」キャラ → 「12時間」の制限と結びつく（サムネに時計のマーク）
  - 紅魔館の家計を預かるメイド → 最後の**「決算」をお嬢様に報告する**流れが自然
  - 冒頭でレミリアが「12時間で人口○万の街を作りなさい」と命令 → **毎回の目標に物語上の理由がつく**
- **スタイルに合う**: 咲夜の「淡々・瀟洒」な語り口が、淡々型の主役に合う。完璧なメイドが初見で失敗する落差が笑いになる
- **解説役が自然**: パチュリーは知識人なので、ゲームの仕組みの補足を言わせても違和感がない。ツッコミも冷静で短く済む
- **見分けやすい**: 銀・青・赤の配色と時計のマークを、サムネ・決算画面の固定の型にできる
- 毎回の流れ: 【冒頭】レミリアの命令 →【本編】咲夜が初見でプレイ、パチュリーが補足とツッコミ →【決算】咲夜が数字を報告、レミリアが評価

### 注意

- 東方キャラの設定を借りるので、東方Projectの二次創作ガイドラインの範囲で使う（`research/RIGHTS.md`）
- キャラ設定に寄りすぎると「東方ファン向け」に見える → 設定は冒頭と決算だけに使い、本編はゲーム中心
- 立ち絵の素材は、商用・収益化の可否を規約で確認してから選ぶ

## チャンネルの雰囲気（2026-10-07 提案 v2。上の「キャラ候補」を置き換える）

ユーザーの条件: 1人／2人の掛け合い／3人以上のわちゃわちゃ、どれでも可。VOICEROID でも可。ゆっくりで2人以上なら**霊夢と魔理沙は外せない**。チャンネルの雰囲気になるので、いい感じに決めてほしい。

### 人数の比較

| 形 | 合う点 | 合わない点 | 判定 |
|---|---|---|---|
| 1人で黙々 | 編集が一番軽い | 初見の「分からない」を拾う相手がいない。60分を1人で持たせるのは上級者向け。**参考例と同じ型** | × |
| **2人の掛け合い** | 初見の主役＋ツッコミ役が初見企画に合う。編集量は中くらい。ながら見で聞きやすい | ゆっくりの定番で埋もれやすい → 役割と看板コーナーで差を出す | **◎ 基本** |
| 3人以上のわちゃわちゃ | キャラが愛されやすい | セリフ量が増え、2週間に1本が遠のく。長時間のながら見には騒がしい | △ 看板コーナーだけ |

声: **ゆっくり（YMM4）**。理由: 「ゆっくり実況」として見つけてもらえる。YMM4 は既に使う予定。VOICEROID／VOICEVOX は差別化にはなるが「ゆっくり」の括りから外れる（※ YMM4 は声に関係なく収益化に AquesTalk のライセンスが必要とされるため、声を変えても費用は減らない。`research/RIGHTS.md`）

### 推奨: 「霊夢と魔理沙の、ゼロから発展させる経営実況」

| 役 | キャラ | 役割 |
|---|---|---|
| 主役（初見でプレイ） | **霊夢** | 大ざっぱで、お金に目がない（貧乏巫女・賽銭箱のネタ）。初見で勢い任せに街を広げて失敗する |
| 相方（ツッコミ・解説） | **魔理沙** | ゲームの仕組みを補足しつつ、霊夢の無茶にツッコむ。計画派 |
| 決算の司会（決算コーナーだけ） | **射命丸 文** | 最後に「文々。新聞 号外」として結果を発表する。見出し＋数字の画面が、毎回の看板になる |

**この形にする理由**
- **お金と発展のゲームに、霊夢の「貧乏・お金好き」が直結する**: 毎回の見どころが「霊夢の街は儲かるのか」になり、最後の決算で「賽銭箱より儲かったか」のような決め台詞が作れる
- **主役は霊夢**: 参考例の主役は魔理沙なので、逆にして被りを避ける
- **3人目は決算だけ**: 文のセリフは1本あたり数十秒〜1分程度。わちゃわちゃ感を少し出しつつ、編集の量は増やさない
- **見分けやすい**: 「号外」の決算画面（新聞の見出し風）をサムネにも使える。赤白（霊夢）＋新聞の白黒＋「12時間」の時計マークを固定の型にする

### 1本の流れ

1. 冒頭（30秒）: 12時間後の街の俯瞰 →「何もない土地から12時間、初見でどこまで行けるか」
2. 本編: 霊夢が淡々と（ときどき暴走して）進め、魔理沙が補足とツッコミ。単調な作業は早送り＋BGMのみ
3. 山場（失敗・急成長）だけ掛け合いを厚くする
4. 決算: 文の「号外」で数字を発表 → 霊夢の一言で締め

### 編集を軽くするための決め事

- セリフは山場に集中させ、作業パートは早送りとテロップ1行で流す
- 決算画面・冒頭・締めは毎回同じテンプレートを使い回す
- 霊夢と魔理沙の口調・決め台詞を決めておき、台本を書く時間を減らす

### 代案

- **霊夢＋魔理沙のみ（文なし）**: 一番軽い。決算は霊夢と魔理沙で発表
- **VOICEVOX（ずんだもん等）で同じ構成**: ゆっくり以外で差別化したい場合。ただし「ゆっくり実況」の視聴者から外れる

## チャンネルの雰囲気 v3（2026-10-07。v2 を置き換える）

ユーザー: **東方原作の設定に準拠しなくてよい**。→ キャラの性格は原作ではなく、**このチャンネルの企画に役立つように決める**。原作ネタ（賽銭箱・新聞など）に頼らないので、東方を知らない人にも伝わる。

### 2人の性格（「勢い」対「計画」）

| | 霊夢（主役・初見でプレイ） | 魔理沙（相方・解説とツッコミ） |
|---|---|---|
| 性格 | **勢い派**。とにかく大きくしたい。数字が増えると機嫌が良くなる。考えるより先に手が動く | **計画派**。効率と数字にうるさい。仕組みに詳しく、霊夢の無茶を止めようとする（たいてい止められない） |
| 担当 | 巨大化・拡張・無茶な挑戦 | 解説・最適化の提案・問題の原因の説明 |
| 決め台詞の例 | 「広げれば何とかなるでしょ」 | 「だから言ったんだぜ」 |

- **発展シミュのいちばん面白い対立「早く大きくするか、計画的に作るか」を、2人の性格にそのまま割り当てる**。初見の失敗も「霊夢の勢いの結果」として自然に見せ場になる
- 3人目は置かない（編集を軽くし、2人の関係をチャンネルの顔にする）。特別回でゲストを出すのは後で検討

### 決算（看板コーナー）

- 毎回同じ「決算書」風の画面。**魔理沙が数字を読み上げ、霊夢が一言で締める**
- 「0時間目 → 12時間目」の数字と、「勢いで得したこと／計画しておけばよかったこと」を1つずつ
- サムネにも同じ決算書のデザインと「12時間」の時計マークを使う

参考にした動画の固有の言い回し・企画・コーナーは使わない。使用禁止リストと公開前チェックは `docs/ORIGINALITY.md`。締めの定型文は独自のもの（霊夢「以上、今期の決算でした」魔理沙「来期はまともな市長でありますように」）を使う。

## チャンネルの雰囲気 v5（2026-10-08。v4 の霊夢・魔理沙の立場を修正）

Cities II の競合2本（ちーさら・きりたん）を見て、**「住民を抑圧する暴君市長＋秘書のツッコミ」は Cities 実況の定番**（きりたんは看板そのもの）と分かった。v4 の「市民をコスト扱いする」はそこに寄るので変える（詳細は `docs/ORIGINALITY.md`「ジャンルの定番と、このチャンネルの立ち位置」）。

| | 霊夢（主人公） | 魔理沙（相方） |
|---|---|---|
| 役割 | **ボケ・お金を溶かす市長**。住民に冷たいのではなく、見栄で自分の街（特に霊夢通り）を盛るためにお金を使う。言い訳がうまい。仕組みは自分で1〜2文で説明する | **ツッコミ・会計係**（秘書ではない）。数字でとがめる。止める（止まらない） |
| 決め文句 | 「必要経費です」（**お金を使う場面だけ**。人の犠牲の正当化には使わない） | 「決算に響くぞ」 |

- 霊夢通りは「自分の名前の道に毎回お金をつぎ込み、毎回失敗の元凶になる」
- 選挙ネタ・立ち退きを笑いの中心にしない
- 決算は会計の言葉（赤字・前期比・特別損失・監査）で、主役は失敗とワースト
