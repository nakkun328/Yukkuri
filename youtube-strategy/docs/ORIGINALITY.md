## ジャンルの定番と、このチャンネルの立ち位置（2026-10-08 追加）

Cities II の競合2本（7・8）を見て分かったこと: **「選挙のない独裁市長」「道路を広げるために住民を立ち退かせて開き直る」は Cities 実況の定番**で、8 はそれが動画の核そのもの。こちらが同じ方向で霊夢の悪役ぶりを作ると、似た動画の1本になる。

| 項目 | ルール |
|---|---|
| 霊夢の悪役ぶり | **住民を抑圧・排除する暴君にしない**。お金・見栄・言い訳（「必要経費です」）で悪くする。霊夢は「住民に冷たい」のではなく「自分の街を盛るためにお金を溶かす」 |
| 魔理沙の立場 | 秘書ではなく**会計係（お金の番人）**。数字でとがめる（7・8 はどちらも秘書役のツッコミ） |
| 選挙ネタ | 使わない（7・8 の両方にある） |
| 立ち退き | ゲーム上起きるのは仕方ないが、**笑いの中心にしない**。決算の数字の1行として出すのはよい（7・8 とも件数は数えていない） |
| 「必要経費です」 | **お金を使う場面だけ**で言う。人を犠牲にする正当化には使わない（8「発展に犠牲はつき物」、9「必要な犠牲」と重なるため） |
| 決算 | 5 の「季節ごとの出荷額発表」と骨格が近い。違いを守る: **①1本に1回だけ ②会計の言葉（赤字・前期比・監査・特別損失）③収益以外の数字も出す（渋滞・霊夢通りへの投資額など）④主役は失敗とワースト** 。発表前の儀式・大げさな換算ボケはしない |
| Stardew Valley | **「12時間＋決算」の型ではやらない**（5 の看板動画と、数字目標・季節発表・ゲームが全部重なる） |
| ツッコミの型 | 「〜します→〜すんな」を毎回の型にしない（5 の定番）。ツッコミは言い方を散らす |

## このチャンネル独自のもの（守る・育てる）

- シリーズの型「初見・ゼロから12時間で、どこまで発展できるか」
- 看板コーナー「決算」（参考4本にない）
- 決め文句：霊夢「必要経費です」／魔理沙「決算に響くぞ」
- 毎回の「霊夢通り」（自分の名前をつけた道が毎回失敗の元凶になる）
- 魔理沙＝会計係、霊夢＝お金を溶かす市長という役割
- 締めの定型文（独自に作る。例：霊夢「以上、今期の決算でした」魔理沙「来期はまともな市長でありますように」）
