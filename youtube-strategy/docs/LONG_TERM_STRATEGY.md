# 長期戦略・最初の10本の仮ロードマップ

最終更新: 2026-10-07 / ステータス: 叩き台（4本目以降は確定ではなく条件分岐）

## 1. 判断ゲート

| ゲート | タイミング | 見るもの | 決めること |
|---|---|---|---|
| G0 | 撮影開始前 | 終了条件・想定プレイ時間・競合状況 | 撮影を始めるか／企画を変えるか |
| G1 | 001公開から7日 | CTR・冒頭30秒維持率・平均視聴率・流入元 | 002の企画の微調整（タイトル型・冒頭の作り方） |
| G2 | 001公開から30日 | 平均視聴時間・長期の再生推移・「他の動画を視聴した視聴者」 | **003を CS2 / Satisfactory のどちらにするか確定** |
| G3 | 002公開から30日 | 001→002 の移動・視聴者の重なり | 4〜6本目の分岐を選ぶ |
| G4 | 3本公開から90日 | 3本の比較・流入元の内訳・長期推移 | チャンネルの客層仮説を更新。7〜10本目の方向 |
| G5 | 10本時点 | 企画フォーマット別の成績 | 勝ちフォーマットを抽出（Phase 9） |

**数値の目安はまだ置かない。** 001 の公開後に、実測値を基準に G1〜G3 のしきい値を決める（新規チャンネルのCTR・視聴時間は一般論が当てにならない）。

## 2. 最初の10本（001〜003 は設計済み、4〜10 は条件分岐）

| # | 内容 | 状態 |
|---|---|---|
| 001 | Minecraft Create 完全自動化の巨大工場 | 設計済み（`videos/001-create/`） |
| 002 | Factorio（終了条件・縛りで一般化） | 設計済み（`videos/002-factorio/`） |
| 003 | CS2 または Satisfactory | **G2 で確定**（CS2 案: `videos/003-cities2/`） |
| 004〜 | 下記の分岐 | 条件付き |

### 4本目以降の分岐（G3 後に選択）

**分岐 A: Createが強く、Factorioへも移動している**（「完全自動化」という体験が効いている）
- 004: Satisfactory（完全自動化フォーマット）
- 005: Create 第2弾（別フォーマット: 制限 or 数字）
- 006: Factorio 第2弾（別フォーマット）
- 007〜010: 勝っているフォーマットを新作・投機枠に展開（Phase 9）

**分岐 B: Createだけ強く、Factorioへ流れない**（Minecraftという入口の力）
- 004: Minecraft×工業の別企画（Create 第2弾 or 別の工業MOD）
- 005: 同クラスタの派生（制限・数字）
- 006: Factorio を一般向けにやり直す企画の再検討（企画の問題か客層の問題かを切り分ける）
- 007〜010: Minecraft 軸を厚くする（ゲーム専門化は最低でも数本のデータを見てから）

**分岐 C: Factorioが強く、Createは弱い**（純粋な工業需要に寄せる）
- 004: Satisfactory
- 005: Factorio 第2弾
- 006: Create の企画やタイトルの見直し（入口を作れていないか）
- 007〜010: 数字・最適化フォーマットを工業ゲームに展開

**分岐 D: 3本目（CS2/Satisfactory）が他と別客層で強い**
- 004〜: その客層のゲーム（都市開発・経営・宇宙など）を試す
- ただし1本の結果で専門化しない。2〜3本のデータを見る

**分岐 E: 3本とも弱い**
- 企画の問題か、パッケージ（タイトル・サムネ）の問題か、尺・構成の問題かを切り分ける
- 競合の再分析（Phase 3 に戻る）。1本あたりの制作時間も見直す

## 3. 投機枠の扱い

- 新作・流行ゲームは**10本のうち1〜2本まで**
- 発売直後に1〜2本で反応を見て、追加投資するかを決める
- 現時点の候補: Arknights: Endfield、Find the Needle（`research/GAME_CANDIDATES.md`）

## 4. 資産化の確認（継続的に）

- 公開後 24時間 / 7日 / 30日 / 90日 / 180日 / 365日 を `experiments/RESULTS.md` に記録
- 企画フォーマット（完全自動化・巨大化・ゼロから・制限・最適化・数字）ごとの成績を比較
- 「時間の投入先」として、1本あたりの制作時間 ÷ 365日後の累計再生で効率を見る
