# 001 動画構成・撮影計画

## 構成テンプレート（成長物語）

| 時間（目安） | 内容 | 狙い |
|---|---|---|
| 0:00 | 最終形を数秒〜十数秒見せる（毎分の生産量・巨大さ） | 完走する理由を作る |
| 0:30 | 開始地点（何もない・手作業） | Before の提示 |
| 〜5:00 | 手作業のつらさ→最初の小さな自動化 | 最初の成功体験 |
| 5:00〜20:00 | 小さな装置の連鎖。規模が見て分かる変化 | 成長の快感 |
| 〜25:00 | **問題発生1**（資源不足・設計ミス・動力不足など） | 山場1 |
| 〜35:00 | 解決・さらに巨大化 | 山場2 |
| 〜45:00 | **問題発生2**（スケールの壁）→大改造 | 中盤の山 |
| 〜55:00 | 最終目標達成 | クライマックス |
| ラスト | 数字で成果を見せる→次動画の予告 | 次への導線 |

## 最初の30秒（案）

1. 最終形（巨大な工場の俯瞰＋自動で動く様子）
2. 「ここまで来るのに○○時間かかりました。最初はこれです」
3. 何もない状態のワールドへ切り替え

## 見せ場リスト（撮影前に10個決めておく）

撮影前に記入: ＿＿＿＿＿＿（例: 最初の自動化に成功した瞬間／最初の大失敗／巨大化の俯瞰／最終稼働）

## 素材の取捨選択ルール（「この作業は動画に必要か」）

- 目標に直結しない寄り道・資源集めの単調作業 → カット／倍速
- 問題と解決が1セットで映っている → 残す
- 成長が目で見える変化（Before/After） → 残す
- 説明が必要な設備が増える場面 → 1行テロップに圧縮
