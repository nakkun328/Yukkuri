# youtube-strategy

ゆっくり実況・YouTube資産形成プロジェクトの管理ディレクトリ。
元の指示は リポジトリ直下の `指示.md`（マスタープロンプト）。

**最重要目標: 数年後も再生され続ける動画資産を積み上げる。動画を作ること自体は目的ではない。**

## 現在地（2026-10-07）

- Phase 1（思想確定）: **進行中** — 矛盾・弱点の洗い出しと戦略批判まで完了。未決事項は `docs/CHANNEL_STRATEGY.md` §3 の「ユーザー判断待ち」
- Phase 2（市場調査）: 初期メモのみ。データ取得に制約あり（`research/GAME_MARKET.md` 冒頭参照）
- Phase 3（競合分析）: 未着手（YouTubeデータにアクセスできていない）
- Phase 4（初期3本の設計）: 叩き台完成 → `videos/00x-*/`
- Phase 5 以降: 未着手

## 読む順番

1. `docs/CHANNEL_STRATEGY.md` — 矛盾の洗い出し・戦略への批判・初期3本の順番の再検討・ユーザー判断待ち事項
2. `docs/LONG_TERM_STRATEGY.md` — 最初の10本の条件分岐ロードマップ・判断ゲート
3. `videos/001-create/idea.md` ほか — 各動画の企画設計
4. `research/GAME_CANDIDATES.md` — ゲームごとの判定（やる / テストする / 今はやらない）

## ディレクトリ

| パス | 内容 |
|---|---|
| `docs/` | チャンネル戦略・視聴者像・柱・動画フォーマット・長期戦略 |
| `research/` | 市場・競合・トレンド・ゲーム候補 |
| `videos/` | 動画ごとの企画・調査・計画・タイトル/サムネ・事後分析 |
| `experiments/` | 仮説の記録と結果（知識ベースの本体） |
| `agent/` | 将来のYouTube戦略エージェントの要件・データモデル・ロードマップ |

## 運用ルール

- ゲーム名・企画を送られたら、`指示.md` §28 の12項目で評価し、最後に **やる / テストする / 今はやらない** を出す
- 数値は必ず出典と取得日を書く。取れていない数値は「未取得」と書き、推測で埋めない
- 投稿前に必ず `experiments/HYPOTHESES.md` に「なぜ伸びると思ったか」を書く
- 初動だけで成否を判断しない。24時間 / 7日 / 30日 / 90日 / 180日 / 365日で見る
