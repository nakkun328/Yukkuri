# 003 Cities: Skylines II（暫定）

ステータス: **未確定**。G2（001公開から30日）で CS2 か Satisfactory かを決める。判断理由は `docs/CHANNEL_STRATEGY.md` §4。

## 一文企画（CS2 案）

**人口10万人の都市を、公共交通だけで渋滞させずに成立させる。**

## 視聴者がクリックする理由

- 「渋滞がない」という結果が、ゲームを知らなくても分かる
- 人口0→10万の Before/After が明確
- 工業ゲームを知らない層にもブランドを広げられるかの検証になる

## ゴール・終了条件

- 人口10万人到達＋ピーク時の渋滞の定量的な成果（平均移動時間・渋滞率などをゲーム内統計で提示）
- **追加コンテンツの状況（Expansion Pass 2: 2026-09-16、Park Adventures: 2026年Q4予定）と現在のパッチ状態を撮影前に確認**。ルールが変わると企画が古くなる

## 想定プレイ時間・完成尺

- プレイ: 20〜30時間
- 完成尺: 45〜60分

| 時間 | 内容 |
|---|---|
| 0〜3h | 街の基礎 |
| 3〜8h | 人口拡大 |
| 8〜15h | 問題発生（渋滞・財政など） |
| 15〜22h | 交通・都市改造 |
| 22〜30h | 最終調整 |

## 最大のリスクと対策

| リスク | 対策 |
|---|---|
| **アップデート依存**で寿命が短い（運営変更・追加コンテンツ・パッチで挙動が変わる） | 「ゲームの挙動」ではなく「都市を作る快感・結果」に寄せる。撮影前に直近パッチを確認。タイトルに仕様名を入れない |
| 人口が小さめ（2026年6月 平均約9,500、ピーク約16,400 ※要再確認） | 上限は小さい。**投資として小さい**と認識し、制作を20時間以内に抑える |
| 工業客層との重なりが未検証（F1） | G2 で001のデータを見て、重なりがなければ Satisfactory に切り替える |
| ゲーム自体の評価・不具合（長期の需要に影響） | 撮影前に直近のレビュー・不具合状況を確認 |
